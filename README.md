# mp-core

Общее ядро сборщиков цен, позиций и статистики маркетплейсов.

Библиотека собрана из кода, который в разных проектах был написан по пять-восемь
раз: обход публичной витрины, клиент платной аналитики, раскладка «строка =
сущность, столбец = дата», ретраи и оповещения. Расхождение копий стоит дорого —
умение, дописанное в одном проекте, не доезжает до соседнего, и там та же
поломка ждёт своего часа.

Реальный случай, из-за которого библиотека и появилась: обход выбранной квоты
платной аналитики через публичную витрину уже был написан в одном проекте, а
таблица соседнего простояла пять суток, потому что там этого кода не было.

## Что внутри

| Модуль | Отвечает за |
|---|---|
| `http` | ретраи и различение отказов: транзиентный / квота / пустой ответ |
| `states` | три состояния замера, которые нельзя смешивать |
| `wb_card` | живая цена с публичной витрины — без ключа и без квоты |
| `mpstats` | история цен из платной аналитики: окно 30 дней, квоты по контурам раздельные |
| `datesheet` | чистая логика листа с датами: шапка, вставка, пропуски, чужие колонки |
| `sheets` | тонкий клиент Google Sheets: ретраи, пачки, лимит записи |
| `notify` | оповещения с нарезкой и адресной шапкой в каждом куске |

## Установка

```bash
pip install "mp-core @ git+https://github.com/<owner>/mp-core@v0.1.0"
```

**Ставить только по тегу.** Потребитель закрепляется на конкретной версии и
переезжает осознанно; ветка `main` в `requirements.txt` означает, что любой
коммит в ядро способен уронить все проекты разом.

## Как этим пользоваться

Цена «сейчас» по списку позиций:

```python
from mpcore import wb_card, states

prices = wb_card.prices(["100000001", "100000002"])
for item, value in prices.items():
    if states.is_price(value):
        print(item, value, "₽")
    else:
        print(item, value)          # «нет в наличии» / «нет карточки»
```

История цен и понятная причина молчания:

```python
from mpcore import mpstats

client = mpstats.Client(token, mpstats.KIND_WB)
newest, probe = client.latest_date(items)
if newest is None:
    print("источник молчит:", client.why_silent())
```

Какие даты не хватает в листе:

```python
from mpcore import datesheet as ds

header = sheet.header("Лист")
cols = ds.date_columns(header, today, first=article_col + 1)
missing = ds.missing_dates(max(cols.values(), default=None), newest)
holes = ds.gap_dates(set(cols.values()) | set(missing),
                     client.available_dates(probe))
```

## Правила, ради которых всё это писалось

1. **Три состояния замера — разные факты.** «Нет в наличии» — про товар,
   «нет карточки» — про идентификатор, «ошибка сбора» — про ЗАМЕР. Последнее
   в таблицу не пишется вообще: дырка замера, записанная как значение, навсегда
   притворится фактом.
2. **Молчание источника не затирает собранное.** Один неудачный прогон не должен
   стирать историю, которую больше неоткуда взять.
3. **Квота — это не «сервис не ответил».** Ретраить её бессмысленно, а в логе
   она обязана называться своим именем, иначе причину ищут в коде сутками.
4. **Колонки ищутся по шапке, а не по буквам.** Люди вставляют свои колонки, и
   привязка к букве уводит запись на соседнее поле.
5. **Дату в шапку писать RAW.** На «умном» вводе «17.08» превращается в дату с
   годом, и следующий прогон не узнаёт собственную колонку.
6. **Пропуски внутри блока дат нужно доливать.** Вставка идёт только слева, и дни
   позади свежей колонки не заполняются уже никогда.

## Разработка

```bash
pip install -e ".[dev]"
pytest -q
```

Тесты не ходят в сеть: транспорт подменяется везде. Прогон ничего не стоит,
ничего не пишет в боевые таблицы и не зависит от доступности внешних сервисов.
