# wb-reglament — книга «Регламент» кабинета WB на Пульте

Модуль стандарта «Пульт» (`../../ПУЛЬТ.md`). Книга сама подтягивает заказы и остатки WB и
считает раскладку FBS-остатка по виртуальным складам. Руками ведутся только выгрузка 1С,
комментарий производства и поставки.

## Меню «📦 Регламент WB»

| Пункт | Что делает | Пишет наружу |
|---|---|---|
| 1️⃣ 🔄 Обновить заказы и остатки WB | лист «WB Данные»: остаток FBS, FBO (графа «Склад WB РФ»), заказы FBS/FBO за 5 завершённых дней; «Регламент» берёт их формулами по артикулу | нет |
| 2️⃣ 🧮 Раскладка FBS: обновить лист и рассчитать план | лист «WB Склады FBS»: заказы и остаток по каждому складу, план по спросу | нет |
| 3️⃣ 🔴 Раскладка FBS: залить план в WB | сухой прогон → подтверждение с цифрой → запись остатков → журнал «_лог FBS» | **да** |
| 📖 / 📊 / 🔌 | инструкция, статус с одним действием, проверка ключа без ретраев | нет |
| 🛠 ➕ Дописать новые товары | новые карточки кабинета — в конец «Регламента» с формулами строки-образца | нет |
| 🛠 ⏰ Автообновление | 06:45 — пункт 2️⃣, 07:15 — пункт 1️⃣ | нет |

## Листы

| Лист | Кто ведёт | Что внутри |
|---|---|---|
| Регламент | человек: G (производство), P–S (поставки), Y (кратность короба) — жёлтые | остальное — формулы от «1С» и «WB Данные» |
| 1С | человек: вставка выгрузки как есть (A — артикул, G — КА, H — ERP) | — |
| WB Данные | книга | перезаписывается целиком пунктом 1️⃣ |
| WB Склады FBS, _лог FBS | книга + ручные D/E/F на листе раскладки | план и журнал заливок |
| Технический (скрыт) | человек | B2 ключ WB, B3 базовый склад FBS, B4 GitHub-токен (пусто, пока репозиторий открыт) |

## Разработка

```
python tools/build.py            # сборка central/build/central.js: node --check, резолв функций лоадера, скан утечек
node tests/run.js                # тесты на стабах GAS
python tools/deploy.py --registry <реестр книг вне репозитория>   # сборка + тесты + clasp push лоадера
node tools/run_local.js ...      # тот же центральный код локально с настоящей сетью (только чтение)
python tools/seed_book.py ...    # заведение новой книги: «Регламент», «1С», «WB Данные», «Технический»
```

Правятся только `central/src/*.js` и `central/preamble.js`. Список запретных слов для скана
утечек — файл из переменной `RG_LEAK_WORDS` (вне репозитория). Отклонения от стандарта —
`module.json`, поле `deviations`.
