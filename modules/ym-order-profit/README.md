# ym-order-profit — ЧП по заказам Яндекс Маркета

Сколько в итоге принесут **заказы вчерашнего дня** — прогнозом по истории своих же заказов,
а не по списаниям вчерашнего дня (Маркет списывает комиссию и буст при доставке, через дни и
недели после заказа, и списания дня — это деньги прошлых заказов).

## Линия заказа

1. Заказ дня (`stats/orders`): штуки, цена продавца = Σ всех `prices[]` (покупатель + доплата
   Маркета + баллы), ставка буста — `items[].bidFee`.
2. Выкуп по артикулу — заказы 14–35 дней назад с известной судьбой.
3. Комиссия — действующий тариф (последние начисления «Размещение товара»).
4. Буст продаж — ставка из заказа × доля ставки, которую Маркет реально списывает (по когорте).
5. Доставка и перевод денег — доля от цены; средняя миля — ₽ на доставленную штуку по свежим
   заказам (8–21 день); эквайринг и невыкупы/возвраты — ₽ на заказ.
6. Себестоимость — из юнитки кабинета, на выкупленные штуки.

Факт удержаний — отчёт `united-marketplace-services`: `commissions[]` в заказе показывает только
остаток сверх взаимозачёта и для расчёта не годится.

## Запуск

```
python tools/pull.py --registry <реестр> --from 2026-08-16 --to 2026-09-20
python tools/write_book.py --registry <реестр> --day 2026-09-20 --days 14
python tests/test_engine.py
```

Реестр — локальный JSON вне репозитория: книга для записи, книга с листом ключей, путь к ключу
сервисного аккаунта, папка данных, кабинеты → лист юнитки и имя файла отчёта услуг.

## Скрипт книги (v1.0.0)

`gas/` — отдельный привязанный проект книги, меню «💰 ЧП ЯМ по заказам»: 1️⃣ посчитать за вчера,
2️⃣ пересчитать листы без Маркета, 3️⃣ пересобрать историю за 14 дней, автопрогон ≈07:10,
статус, проверка связи. Логика расчёта — `gas/3_модель.js` (один в один с `tools/yop_engine.py`),
сбор — `gas/2_сбор.js`, листы — `gas/4_листы.js`, кэш на Диске — `gas/5_кэш.js`.
Каждое утро докачиваются заказы, созданные вчера, заказы со сменой статуса за вчера и отчёт
«Стоимость услуг» за вчерашние начисления; кабинеты идут очередью с продолжением.

```
python tools/seed_cache.py --registry <реестр> --out <папка>     # засев кэша из локального сырья
python tools/deploy_gas.py --registry <реестр>                   # заливка скрипта, сверка состава
node tests/run_gas_stub.js <реестр> <день>                       # запись листов на заглушках
```

Отклонения от «Пульта» — в `module.json`.
