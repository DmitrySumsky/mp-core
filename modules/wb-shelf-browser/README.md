# wb-shelf-browser — сбор полок и цен WB из браузера

С 22.09.2026 WB не пускает облако к витрине. Полки конкурентов и цены для книг
брендов снимает расширение в Chrome менеджера — по кнопке из любой книги.

```
книга бренда ─ «🌐 Обновить все книги через браузер» ─▶ вкладка WB #wbshelf=brands
расширение ─ план ◀── хаб (Apps Script) ◀── облако: browser_job.py plan
расширение ─ итог ──▶ хаб ──▶ GitHub Actions browser-apply.yml ──▶ все книги контура
```

## Установка расширения (менеджеру, один раз)

1. Взять папку `wb-shelf-browser-vX.Y.Z` (её собирает `tools/build_ext.py`;
   в ней лежит ключ хаба, поэтому в git её нет — передаётся лично).
2. Chrome → `chrome://extensions` → включить «Режим разработчика» (справа сверху).
3. «Загрузить распакованное» → выбрать эту папку. Должно появиться «Полки WB».
4. Проверка: книга бренда → «Полки WB» → «🌐 Обновить все книги через браузер»
   → «Открыть WB и начать сбор». В правом верхнем углу вкладки WB появится
   тёмная панель со счётчиком полок.

## Что видно и что делать

- Панель «Полки: N из M» — идёт сбор, вкладку не закрывать (работать можно
  в других вкладках).
- «WB попросил проверку браузера» — обновить страницу (F5), пройти проверку,
  если WB её покажет; сбор продолжится с того же места.
- «Готово» — книги всех брендов обновятся сами через 3–5 минут.

## Для разработчика

- Хаб: `python tools/deploy_hub.py --keys <api_keys_extra.txt>` — первая
  заливка заводит книгу хаба и публикацию; после неё владелец один раз
  открывает адрес веб-приложения и разрешает доступ.
- Расширение: правка `extension/*` → поднять `version` в `manifest.json` и в
  шапке `content.js` → `tools/build_ext.py` → раздать папку.
- Ключи: `SHELF_HUB_KEY`, `GH_PAT_SHELF_BUTTON` — в файле ключей вне репо;
  в облаке — секреты `SHELF_HUB_URL` / `SHELF_HUB_KEY` репо wb-shelf-positions.
