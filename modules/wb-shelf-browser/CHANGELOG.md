# wb-shelf-browser — история версий

## v1.0.0 — 22.09.2026

WB ЗАКРЫЛ ВИТРИНУ АНТИБОТОМ — с ночи на 22.09 `recom.wb.ru`, `card.wb.ru`,
`search.wb.ru` отдают 403 любому клиенту без проверки браузера; полки и цены
книг брендов из облака встали целиком.

- Расширение Chrome (MV3): по метке `#wbshelf=<контур>` на www.wildberries.ru
  берёт план из хаба и снимает полки (`/__internal/u-recom/…`) и карточки с
  ценами (`/__internal/u-card/…`) запросами самой страницы — с куками вкладки
  и заголовком `deviceid` сайта. Полку листает, пока не найдёт все наши
  карточки. На 403/498 встаёт на паузу и просит обновить страницу; прогресс
  хранится, после F5 сбор идёт дальше.
- Хаб (Apps Script, веб-приложение от имени владельца): план ↔ итог, статус
  «когда собирали и кто», запуск разноса по книгам в GitHub Actions.
- Как делает «ТурбоМинимум» v80 (разобран 22.09): проверку WB проходит
  человек, расширение её не решает и пропуск не подделывает.
- Проверено: 40 полок и 200 карточек за ~25 с без блокировок.
