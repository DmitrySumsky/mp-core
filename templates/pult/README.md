# Шаблон модуля «Пульт»

Стандарт целиком — `../../ПУЛЬТ.md`. Здесь — заготовки, с которых начинается новый модуль.

| Файл | Что это |
|---|---|
| `loader.gs` | тонкий лоадер книги: меню, `run_()`, HTML-диалог, витрина скоупов |
| `central_head.js` | шапка центрального кода: версия, блок истории, обязательный минимум функций |
| `module.json` | контракт модуля для общих инструментов монорепозитория |

Порядок заведения:

1. Скопировать шаблон в `modules/<имя>/`, заменить `<МОДУЛЬ>`, `GH_*` и пункты меню.
2. Завести приватный репозиторий (или каталог модуля) под центральный файл, выдать книге
   токен с правом Contents: Read-only, вписать его в «Ключи» B4.
3. Собрать центральный файл сборкой со встроенными проверками (`node --check`, резолв
   публичных функций, скан утечек) и задеплоить — тем же заходом, что и правку кода.
4. Залить лоадер в книгу (`clasp push -f`), проверить «ℹ️ Версия кода».
5. Пройти чек-лист приёмки из `ПУЛЬТ.md` §13.

Эталонные реализации в бою: разгруз Ozon (лоадер v9 + central v2.52.0), раскладка FBS,
управление ценами, ответы на отзывы.
